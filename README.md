# Routines

To-do-App für wiederkehrende Routinen auf iPhone, iPad und Mac (SwiftUI, SwiftData).

- Planung, Architektur und Konventionen: [`Docs/PROJECT.md`](Docs/PROJECT.md). Bitte vor Änderungen lesen, auch als Kontext für KI-Assistenten.
- Xcode-Projekt: `Routines/Routines.xcodeproj`
- Logik und Datenmodell: lokales Swift Package `Routines/RoutineKit`
- Tests: Scheme „RoutineKit“, Ziel „My Mac“, ⌘U
- Simulator mit Testdaten: Scheme „Routines (Testdaten)“ (Startargument `-sampleData`)
